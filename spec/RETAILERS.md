# One item, many sellers

Obtain breadth through shopper-triggered discovery. Establish truth per merchant and listing. Every offer must meet the exact same buyer constraint to enter the same winner set. Give each adapter a short deadline; return partial coverage and observe rate limits. Keys: GEMINI_API_KEY, optionally SERPAPI_KEY and BESTBUY_API_KEY. Commerce APIs and billing are independent of model quota.

**First-source fallback.** Timebox key provisioning to ten minutes. In parallel, select one allowed merchant-page adapter or a merchant-owned authorized feed. Use a real response for one non-Shop chain if possible. If only one verified seller is available on a run, present exactly that. Reachable pages and affiliate feeds do not automatically grant retention, republication or model-evaluation rights. A user-uploaded fresh screenshot is explicitly labeled supplied evidence and is separate from a live-adapter result.

**Permission by operation.** For each source register permission/terms reference and capabilities for on-demand discovery, price display, repeated reads, retention and offsite ML evaluation separately. Global Catalog price/availability caching is capped at ten minutes; this app uses an even shorter eligibility window. Keep it shopper-triggered. Do not feed restricted external offer data to an ML/evaluation job, or persist it as watch history. Link-only discovery is a valid result for an unsupported retailer. Use rights-cleared merchant evidence for the five-case offline evaluation, with source rights recorded before either arm runs.

**Normalize carefully.** Convert decimal USD to integer cents with Decimal and reject fractional cents. Compare like condition, variant, edition, pack count, financing/membership status, market, fulfillment, seller and price basis. Unknown stock, preorder, club-only, subscribe-and-save, a teaser “from” price, a missing mandatory fee and a private listing are distinct from purchasable evidence. Join one seller's duplicate representations; quarantine fresh contradictory fields from credible sources instead of taking their cheaper one. Preserve read/effective time and timezone. Do not manufacture availability after a 403/429 or silently convert an unknown tax to zero. One real source with three distinct verified merchants is three sellers and one integration.

**Development smoke:** LEGO Botanicals Mini Orchid 10343, UPC 673419404235, is one known multi-retailer product used for adapter development. Do not put its prices in code, use it in the final five-case holdout, or use it as the only working demo. Source references and onboarding links are in ops/SOURCES.md.


## Ready-to-use merchant feed integration

A trusted, rights-cleared retailer export can join Shop in the live photo CLI now. Set SIGNALFORGE_MERCHANT_EXPORT on the server to a local JSON file supplied by a real authorized producer. Required top-level fields are feed_id, anchors, offers. Anchors use the schema in INTERFACES.md. Offers use buyer.evaluate fields; read_at must be the effective source observation time. An optional target_gtin scopes a related wrong-variant row to the comparison, and an optional shop_seller_aliases object maps verified identical seller identities. Use a stable canonical listing identifier across adapters where available. The code discovers anchors by checked barcode or printed brand+MPN, asks Carbon to bind the item, requests Shop prices on demand, and returns one cross-source result. US-wide Shop rows stay in the national cohort. Region-specific ranking needs regional evidence. A team-authored or synthetic export is development data and cannot be called live retailer evidence. Without the export, the CLI uses the on-demand Shop path. This export and the authorized watch export use different schemas and permissions.
