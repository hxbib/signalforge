## v1 · what failed
Source: `eval/results/pairs-v1.json` (scored run) and `eval/results/diagnostic-v1.json`. The diagnostic is a post-hoc
re-run of the system arm's two calls on the v1 system-arm failures, done only to see which abstention rule fired. It is
not a score, and its model outputs can differ from the scored run.

- **The system arm made no wrong calls.** All of its v1 failures are abstentions on pairs whose gold label is `match`.
  Neither arm made a false accept on the 20 true non-matches.
- **Class 1: Carbon abstains when no manufacturer model number is printed** (pair-06, -09, -11, -20, -26, -38,
  -39). Typical cases are accessories and consumables with generic titles (a GoPro hand grip, Instax film twin pack, a
  Case Logic bag whose two listings are identical text), or colour/edition details on only one side. The PAIR prompt
  says "if decisive evidence is absent, abstain", and Carbon applies that, so it disagrees with Neon's tentative `match`
  and the pair abstains. The single-call baseline also abstains on most of these (see the paired counts). This is the
  intended conservative behaviour for identity tier `model_number`: the live app only promotes a listing on an exact
  printed model number, so abstaining here costs recall, not safety. We did not change it, because loosening it is
  exactly what would create false bargains.
- **Class 2: the verbatim-quote check rejects genuine quotes** (pair-25, pair-37). In pair-25 Neon collapsed a
  newline in the source (`…KitPart Number(s)\nOption…`) into a space. In pair-37 Carbon joined two verbatim fragments
  of a spec table with `...`. The check is a raw case-folded substring test, so both real quotes failed it and a
  correct `match` became an abstention.
- **Class 3: run-to-run variance** (pair-01). v1 abstained. In the diagnostic re-run both models said `match` with
  verbatim quotes. One sample per case cannot settle variance; we report it rather than re-scoring.

## Proposed change (the only one)
- `ASK @MODELS` (board, 15:57 ET): in `app.models.pair`, normalise whitespace on both the quote and the field before
  the substring test, and split a quote on `...` / `…` so that every non-empty fragment must appear verbatim on the same
  side. Text the model invents still fails the check. This targets class 2 only. Class 1 is left as designed.
